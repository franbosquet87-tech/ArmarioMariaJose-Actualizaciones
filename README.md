# Actualizaciones · El armario de María José

Canal público de **actualizaciones de interfaz HTML**, independiente del repositorio Android privado.

El canal contiene únicamente `updates/latest.json` y `updates/app-ui.html`. No deben subirse copias de seguridad, fotos personales, información del inventario ni claves privadas.

La aplicación utiliza HTTPS y comprueba la integridad SHA-256 del archivo HTML antes de instalarlo. Las actualizaciones de interfaz conservan los datos locales de la aplicación; no sustituyen una APK firmada para cambios en el código Android.

Canal: `https://raw.githubusercontent.com/franbosquet87-tech/ArmarioMariaJose-Actualizaciones/main/updates/latest.json`
